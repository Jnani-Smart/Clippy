# Clippy v1.6.0 Release Notes

## Release Date: July 3, 2025

We're excited to announce the release of Clippy v1.6.0, which focuses on visual consistency and UI improvements.

## What's New

### New App Icon
- **Completely refreshed app icon** with improved high-resolution assets
- **Consistent icon appearance** across all macOS contexts (Dock, Finder, About section)
- **Enhanced icon handling** throughout the app

### UI Improvements
- **More compact selection toolbar** in clipboard view for better screen real estate
- **Improved alignment** of UI components
- **Enhanced visual consistency** across the app

### Technical Improvements
- **Optimized icon loading** in the About section
- **Improved handling of macOS icon caches**
- **Updated asset catalog** with consistent high-resolution assets

## Bug Fixes
- Fixed inconsistencies with app icon appearance in various contexts
- Resolved issues with icon caching in macOS

## Upgrading
To upgrade to Clippy v1.6.0, simply download the latest version from our website or use the built-in auto-update feature.

## Feedback
We're always looking to improve Clippy! If you have any suggestions or encounter any issues, please let us know through our GitHub repository or support channels.
